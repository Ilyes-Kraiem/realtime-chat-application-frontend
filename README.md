# 🚀 Real-Time Chat Application – Frontend

## 📌 Overview

This is the **frontend** of a real-time chat application built with **React.js**.
It provides a responsive and interactive user interface that allows users to communicate instantly using WebSocket technology.

The application focuses on delivering a smooth user experience with real-time updates, modern UI design, and efficient state management.

---

## ✨ Features

### 💬 Chat Interface

* Sidebar with user search and chat list
* Real-time message display
* Sender vs receiver message styling
* Scrollable chat window

### ⚡ Real-Time Messaging

* Integrated **Socket.IO client**
* Instant message updates without page refresh
* Live synchronization between multiple users

### 👤 User Experience

* Online / offline status indicators
* Dynamic chat switching
* Clean and responsive UI

### 🔗 API Integration

* Connected to backend APIs for:

  * Authentication
  * Chat retrieval
* Uses Axios for HTTP requests

---

## 🧠 State Management

* Built using React Hooks:

  * `useState`
  * `useEffect`
* Manages:

  * Active chat
  * Messages
  * User session

---

## 🛠️ Tech Stack

* React.js
* JavaScript (ES6+)
* Socket.IO Client
* Axios
* CSS
